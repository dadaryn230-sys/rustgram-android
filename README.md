# RustGram для Android

**RustGram** — независимая сборка на основе исходного кода AxGram (который, в свою очередь, основан на Nagram и Telegram for Android). Проект предназначен для личного использования и дальнейшей разработки. Это неофициальный клиент, не связанный с Telegram Messenger LLP.

## Текущая основа

В исходниках уже присутствуют реализации следующих функций. До выпуска RustGram они будут отдельно проверены на сборке и на устройстве:

- локальное сохранение полученных сообщений перед удалением;
- история обнаруженных редакций сообщений;
- Ghost Mode и управление отправкой отдельных статусных событий;
- локальный архив полученных одноразовых медиа;
- архивирование файлов и управление лимитом локального хранилища;
- темы и дополнительные настройки интерфейса;
- дополнительные папки и аккаунты.

Локальный архив не может восстановить данные, которые приложение не получило. Точное время посещения, скрытое сервером Telegram от текущего аккаунта, клиент достоверно получить не может. В RustGram не будет показываться выдуманное время или обход серверного ограничения как якобы точный результат.

## Идентичность приложения

- Отображаемое имя: **RustGram**.
- Android applicationId: **one.rustgram.android**.
- Ветка разработки: **rustgram-dev**.
- Базовая ветка: **axgram** (не изменять напрямую).

Отдельный applicationId позволяет установить RustGram рядом с официальным Telegram и исходным AxGram.

## Сборка на Windows

Проверенные требования исходной сборки:

- JDK 17;
- Android SDK и Build Tools 35.0.0;
- Android NDK 27.3.13750724;
- Gradle Wrapper 8.11.1;
- MSYS2 с make, nasm, yasm и patch.

### 1. Собственные Telegram API credentials

Создай приложение на https://my.telegram.org и получи собственные api_id и api_hash. Не используй ключи AxGram или другого клиента.

Создай в корне проекта файл local.properties (он игнорируется Git) и заполни:

```properties
sdk.dir=C:/Users/USER/AppData/Local/Android/Sdk
TELEGRAM_APP_ID=ТВОЙ_API_ID
TELEGRAM_APP_HASH=ТВОЙ_API_HASH
KEYSTORE_PASS=ПАРОЛЬ_ХРАНИЛИЩА
ALIAS_NAME=rustgram
ALIAS_PASS=ПАРОЛЬ_КЛЮЧА
```

Gradle намеренно завершит конфигурацию с ошибкой, если собственные Telegram API credentials не заданы. Это предотвращает случайную сборку с ключами upstream-проекта.

### 2. Собственный ключ подписи APK

Из корня проекта выполни:

```powershell
keytool -genkeypair -v -keystore TMessagesProj/release.keystore -alias rustgram -keyalg RSA -keysize 4096 -validity 10000
```

Сохрани keystore и пароли в надёжном месте. Обновления Android-приложения должны быть подписаны тем же ключом. Не загружай keystore или пароли в GitHub.

### 3. Firebase push (необязательно)

Конфигурация Firebase из исходного AxGram удалена, чтобы RustGram не отправлял push-токены в проект другого разработчика. Без собственного Firebase-конфига FCM push не настраивается; для полноценной фоновой доставки уведомлений нужно подключить свой Firebase-проект и поместить его google-services.json в TMessagesProj/. Gradle применит Google Services plugin только при наличии этого файла.

### 4. Сборка

В терминале Windows из корня проекта:

```powershell
gradlew.bat :TMessagesProj:assembleDebug
```

Выходные APK находятся в:

```
TMessagesProj/build/outputs/apk/debug/
```

Для Redmi Note 11 Pro выбирай вариант arm64-v8a.

## Rust

На текущем этапе исходный Telegram-клиент использует Java/Kotlin и нативные C/C++ компоненты. Rust пока не является частью сетевого ядра AxGram. Внедрение Rust будет отдельным этапом: сначала нужно получить воспроизводимую базовую сборку, затем выбирать изолированные модули для переноса и проверять выигрыш тестами. Полная перепись MTProto на Rust не входит в первый этап.
